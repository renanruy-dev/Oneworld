# Diretrizes do Projeto OneWorld

## Gerenciamento de Git e Branches (Regra Mandatória)
- **NÃO crie branches locais**: Nunca crie nenhuma branch local nova, a menos que o usuário solicite expressa e explicitamente.
- **Trabalhar sempre na `main`**: Todo e qualquer código, configuração, correção ou nova funcionalidade deve ser implementado e modificado diretamente na branch `main`.
